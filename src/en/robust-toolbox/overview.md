# Robust Toolbox

**RobustToolbox** (RT) is a custom game engine, primarily developed for [Space Station 14](https://spacestation14.com/). Key features include:

* Both game content and engine are mostly written in C#, with a focus on seamlessly developing both at once.
* Well-developed client/server authorative network model.
* Flexible & easy-to-use ECS for gameplay logic.
* Content & packaging model allows content to be delivered by game servers with little limitations.
* No heavy tooling required to contribute and develop.
* If I were better at marketing, there would be more bullet points.

```admonish info "A note on custom games"
While RT can totally be used by games other than SS14, at the end of the day it is still developed for SS14 first and foremost. If you want to use it for your own project, know that it will be a hands-on experience that will never be as easy as an off-the-shelf game engine like Godot would provide.

Of course, we are always open to improvements in this area (both in documentation, and the engine itself).
```

The information in this section is mostly *reference* documentation. It is not intended to be your first exposure to the engine, and it is not required to read the entire thing in full. It is also not organized into any particular recommended reading order.
